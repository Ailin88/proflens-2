
# PROOFLENS 2.0
### Prove Your Potential

GAMBIT Hackathon 2026 | HackHub
Case: Talent to University

## About the Project
PROOFLENS is a web application that helps students
prepare their projects and enables experts to evaluate
and compare them using transparent criteria.

## The Problem
Student projects are different, making consistent
evaluation and meaningful feedback challenging.

## Our Solution
PROOFLENS provides:
- Student project submission
- Project readiness analysis
- Weighted expert evaluation
- Detailed scoring breakdown
- Project saving and comparison
- Expert comments
- Project deletion

## Technologies
HTML5, CSS3, JavaScript, localStorage.

## Evaluation Criteria
- Problem relevance: 20%
- Innovation: 25%
- Feasibility: 25%
- Evidence and results: 30%

## How to Run
Open index.html in a modern web browser.

## Limitations
This is a hackathon MVP.
Scores are assigned by human experts.
There is no automatic AI scoring.
Projects are stored locally in the browser.
There is no shared database or authentication.

## AI Tools Disclosure
ChatGPT was used for brainstorming, code generation,
debugging, documentation and product planning.
The team tested and adapted the implementation.

## Research
